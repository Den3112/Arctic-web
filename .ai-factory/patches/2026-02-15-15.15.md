# Patch: Fix Pie Chart Visual Artifact

## Context

The user reported a "square" visual artifact overlaying the Pie Chart in the Reports view. This was identified as the default `Tooltip` cursor behavior in Recharts, which renders a shape highlighting the active payload.

## Changes

- **ReportsView.tsx**:
  - Added `cursor={false}` to the `<Tooltip>` component within the `PieChart`.
  - This disables the default hover shape/cursor, leaving only the custom tooltip content.

## Verification

- **Visual**: The white square outline should no longer appear when hovering over the chart.
- **Functionality**: The custom tooltip (glass card) should still appear as expected.

## Prevention

- When using custom tooltips in Recharts, explicitly disable default cursors if they clash with the design.
