# Patch: Restore Pie Chart Visualization

## Context

The user reported a regression in the Pie Chart visualization on the Reports page. The previous "active shape" implementation was missing labels for non-hovered segments ("clearly visible all names") and appeared off-center.

## Changes

- **ReportsView.tsx**:
  - Replaced custom `renderActiveShape` with a standard `Legend` component to show all project names.
  - Added `label` prop to `Pie` to show names directly on the chart segments (if > 5%).
  - Adjusted `Pie` radius and centering (`cy="45%"`) to accommodate the Legend at the bottom.
  - Fixed TypeScript errors related to `Legend` payload and `midAngle`.
- **en.ts**:
  - Added missing translation keys: `timeDistribution` and `completedTasks`.

## Verification

- **Visual**: Chart should now show a Legend at the bottom with all project names and values. Segments with > 5% value will have labels.
- **Type Safety**: No TypeScript errors in `ReportsView.tsx`.
- **Responsiveness**: `ResponsiveContainer` ensures it fits within the card.

## Prevention

- Ensure UI components that rely on visual data (Charts) usually have a Legend or clear labeling strategy by default.
- Check translation keys when restoring or modifying UI text.
