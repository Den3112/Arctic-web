# Contributing to ArcticTime

First off, thank you for considering contributing to ArcticTime! It's people like you that make ArcticTime such a great tool.

## Code of Conduct

By participating in this project, you are expected to uphold our Code of Conduct.

## How Can I Contribute?

### Reporting Bugs

- Use the **Bug Report** template when opening an issue.
- Clearly describe the issue including steps to reproduce.
- Include environment details (browser, OS).

### Suggesting Enhancements

- Use the **Feature Request** template.
- Explain why this feature would be useful to most users.

### Pull Requests

- Fork the repository and create your branch from `main`.
- If you've added code that should be tested, add tests.
- Ensure the test suite passes.
- Make sure your code follows the existing style (run `npm run lint`).

## Style Guide

- Use TypeScript for all new code.
- Follow the 2-space indentation rule (defined in `.editorconfig`).
- Use descriptive variable and function names.
- Keep components small and focused.
